# Project Guidelines & Memory

## Git Commit & Pull Request Conventions
- **DO NOT use conventional commit prefixes**: Never use prefixes such as `feat:`, `fix:`, `feat!:`, `fix!:`, `chore:`, `docs:`, `style:`, `refactor:`, `test:`, `build:`, `ci:`, etc. in Git commit messages, branch names, or pull request titles.
- **Natural language messages**: Write clean, professional, descriptive sentences (e.g., "Add interactive difference highlighting in PDF compare mode" instead of "Feat: Add interactive...").
