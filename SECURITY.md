# Security Policy

## Supported Versions

The following versions of the TeamSync PDF Viewer SDK and service components currently receive security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.8.x   | :white_check_mark: |
| 1.7.x   | :white_check_mark: |
| < 1.7   | :x:                |

## Reporting a Vulnerability

We take the security of TeamSync PDF Viewer and our users seriously. If you discover or suspect a security vulnerability, please report it privately through one of the following channels:

- **GitHub Private Vulnerability Reporting**: Submit an advisory directly via the [Security Advisories](https://github.com/angelbot-ai/TeamSync-PDF-Viewer/security/advisories/new) page.
- **Security Team Email**: Send details to `security@teamsync.com` (or `security@angelbot.ai`).

### What to Include in Your Report
To help us triage and resolve the issue quickly, please provide:
- A clear description of the vulnerability and its potential impact.
- Affected component(s) and versions.
- Step-by-step reproduction instructions or a conceptual proof of concept.
- Any suggested remediations or mitigations.

### Response Timeline
- **Acknowledgment**: Within 2 business days of receipt.
- **Triage & Verification**: Within 5 business days.
- **Fix & Advisory Release**: Coordinated with the reporter, aiming for resolution within 14 to 30 days depending on severity.

Please do not disclose security issues publicly before a coordinated patch has been published.
